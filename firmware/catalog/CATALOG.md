# ZC signal catalogue `vehicle-body` v1

Generated by `zcgen.py` from `vehicle_body.yaml` (+ `core.yaml`); do not edit. Catalogue hash (HEARTBEAT): **0xd787a7ec**.

Every message is the 20-byte ZC header (`t1s_node/zc_core.h`) + the payload below, little-endian, packed.
Profile: **vss** (gateway: Zenoh key = `vehicle/<lower-case VSS path>`). Hooks carried for: ros2, uorb, ngva.
