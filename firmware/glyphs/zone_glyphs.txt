# The LED panels' pictures: pixel fonts, tell-tale icons, the indicator arrow and the colours, for the two 10x10
# WS2812 panels of the body endpoint (one 20x10 frame). The single source for the zone controller's C renderer
# (t1s_node/zone_glyphs.h) and the bench console's Python one; `python3 glyphgen.py` writes both (--help).
#
#   @color <name> <r> <g> <b>     a colour at full scale (the brightness setting multiplies it later)
#   @font <name> <height>         the glyphs below it, each ":<name>" (one character, or a word) and then
#                                 <height> rows of '#' (lit) and '.' (dark), all rows the same width
#
# Brightness: every colour here is the most a pixel ever gets before the brightness setting. Tell-tales (tt_*)
# sit below the gauges they share a panel with (the eye should land on gear and speed first), white is capped at
# 200 (150 for tell-tales) since three channels at full make the harshest pixel, and blue keeps its full channel
# because a WS2812's blue looks darker than its red or green at the same value.

# gauges and lamps
@color amber 255 110 0
@color red 255 0 0
@color white 200 200 200
@color green 0 220 60
@color violet 170 60 255
@color dim 40 0 0
# gear letters
@color gear_P 255 60 60
@color gear_R 230 230 230
@color gear_N 255 170 0
@color gear_D 40 255 90
# tell-tales
@color tt_blue 0 70 255
@color tt_green 0 170 50
@color tt_amber 230 100 0
@color tt_red 220 0 0
@color tt_white 150 150 150
@color tt_cyan 0 180 200
@color tt_dot 160 160 160
