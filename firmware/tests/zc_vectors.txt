# Golden vectors for the ZC core frame (t1s_node/zc_core.h), version 1.0.
# Written by hand from the byte table in zc_core.h, not produced by either encoder: the C test
# (zc_core_test.c) and the bench console's Python encoder (t1s-zone-bench tools/zc_core.py,
# tests/test_zc.py) must both reproduce these bytes and decode them back to these fields.
#
# One message per line: <kind> <name> key=value ... hex=<bytes>; hex= takes the rest of the line, spaces ignored
#   kinds with a payload: every catalogue item by its c name (state_in sensors_out zone_diag indicator heartbeat
#   gear_target motion_cmd motion_telemetry) and ack
#     header keys: version (default 0x10) type id cls flags seq ts
#   reject: hex must fail to decode with err (-1 short, -2 magic, -3 major, -4 payload too short for the id)
#   wire:   zc_wire_of(hex) == wire (0 unknown, 1 zc, 2 VST1/VST2, 3 SNS1, 4 legacy T1S-EVT)
# Numbers are decimal or 0x hex.
